# OpenViking × OpenClaw × LoCoMo10 Reproduction Repository

This repository corresponds to `repro_spec_v2.md`. The goal is not just to "crank out a set of numbers first," but to provide a reproduction experiment harness that is **publicly auditable, repeatable for secondary runs, and capable of distinguishing the boundaries of strict / compatibility / exploratory claims**.

The scientific baseline of the repository is strictly based on `repro_spec_v2.md`, `env/group_definitions.json`, `env/claim_decisions.json`, and `env/public_evidence_manifest.json`. Among them:

- `row1-memory-core`, `row2-memory-lancedb`: strict mainline
- `row3-openviking-minus-core`: currently still executed and reported under the compatibility baseline
- `row4-compat-primary`: compatibility mainline
- `row4-exploratory-legacy-nonslot`: appendix / exploratory only, will not be included in the main results table.

**The single source of truth for public claims is `env/claim_decisions.json`.**

## Scope and Baselines

Main execution lines:

- `row1-memory-core`
- `row2-memory-lancedb`
- `row3-openviking-minus-core`
- `row4-compat-primary`

Appendix lines:

- `row4-exploratory-legacy-nonslot`

This repository adheres to the following hard constraints:

- Official results are only allowed through the OpenClaw gateway
- Official groups are prohibited from using `eval.py --viking`
- Ingest and QA must explicitly pass the same user id
- `parallel` is fixed to `1`
- Ingest `tail` is fixed to `[remember what's said, keep existing memory]`
- Source / benchmark / env / config snapshots must be frozen
- Do not reuse old storage, workspaces, sessions, or caches
- Do not change versions, model routing, or configurations midway through a full run
